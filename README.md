# KB-TKIT As-Salaam

Website profil dan informasi PPDB KB-TKIT As-Salaam, Bekasi.

## Menjalankan

Buka `index.html` di browser. Website ini menggunakan HTML, CSS, dan JavaScript tanpa proses build.

## Aset

Foto, logo, QR code, dan gambar lainnya tersimpan di `assets/images/`. Ikon SVG tersimpan di `assets/icons/`. Nama file gambar menggunakan huruf kecil dan tanda hubung. Pastikan path aset diperbarui di `index.html` apabila nama atau lokasi gambar berubah.
